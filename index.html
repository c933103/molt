Keep this tab open. Refreshing or closing it clears the key. No key is saved to the site or browser storage.

Using this with dot
  1. Ask dot to open this page in its browser.
  2. Take over that browser and enter the key here.
  3. Select Connect, then return control to dot.
  4. Ask dot to use the page’s buttons and forms. It does not need to copy the key.

Your personal browser and dot’s cloud browser have separate sessions. A website cannot override dot’s action permissions.

Credential limits

This is a browser-held credential, not a server-side vault. Code running in this page, browser extensions, browser inspection tools and someone controlling this browser can access it. Only use a copy whose source you trust.
